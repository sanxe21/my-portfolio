Вход в админку

Админка сохраняет кейсы прямо в репозиторий сайта на GitHub. Для входа нужен ключ доступа (токен). Его создают один раз.

  1. Откройте создание токена на GitHub (Settings → Developer settings → Fine-grained tokens).
  2. Token name — например, pvltsk-admin. Expiration — до года.
  3. Repository access → Only select repositories → my-portfolio.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Нажмите Generate token, скопируйте ключ и вставьте ниже.

Ключ хранится только в этом браузере и отправляется только на GitHub. Никому его не передавайте. Если потеряли устройство — удалите токен на GitHub.
